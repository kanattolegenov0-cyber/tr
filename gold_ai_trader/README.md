# Gold AI Trader — первый исследовательский этап

Изолированное приложение для изучения XAUUSD. В нём нет вызовов исполнения сделок; исходный репозиторий всё ещё содержит торговый бот и MQL5-советники. Не запускайте их. Прочитайте [аудит](AUDIT.md). Этот этап не реализует ИИ, сигналы для торговли, paper trading, Telegram или веб-интерфейс.

## Установка на Windows

Установите Python 3.11+ с python.org и откройте CMD. Из корневой папки репозитория:

```bat
py -3 -m venv .venv-gold
.venv-gold\Scripts\python.exe -m pip install -r gold_ai_trader\requirements.txt
.venv-gold\Scripts\python.exe -m pytest gold_ai_trader\tests -q
```

Проект также доступен в отдельной папке внутри репозитория. Исходные торговые скрипты не включайте и не запускайте.

## Анализ и тест

Подготовьте CSV с заголовком `timestamp,open,high,low,close`, где timestamp — ISO 8601 с часовым поясом, желательно UTC. Для времени без часового пояса предполагается UTC. Укажите только **закрытые** свечи, строго по времени и без повторов. Поддерживается Parquet с теми же столбцами. Входные цены считаются ценами Bid. Укажите наблюдённый спред в долларах за единицу золота — он не задаётся автоматически:

```bat
.venv-gold\Scripts\python.exe -m gold_ai_trader.app C:\path\gold.csv --spread 0.30 --slippage 0.05 --commission 0 --units 1 --output gold-output
```

EMA20 и EMA50 определяют направление на закрытии свечи; изменение виртуальной позиции происходит на следующем открытии. BUY исполняется по Ask (Bid + фиксированный спред), SELL по Bid; проскальзывание ухудшает цену. Комиссия в USD за сторону. Результаты `trades.csv` и `equity.csv` содержат только модельные значения. Открытая в конце позиция учитывается в equity и не закрывается автоматически. Размер `units` — условное количество, не лоты XM. Это предварительный расчёт без свопа, рыночных разрывов, stop-loss, take-profit, лимитов риска и индивидуальной спецификации XM; неприменим для оценки реальной стратегии.

## MT5: только чтение

Модуль `mt5_reader.py` рассчитан на официальный MetaTrader5 в Windows, подключённый к уже работающему терминалу с демосчётом. `connect()` отклоняет остальные типы счетов; `symbols()` находит GOLD и XAUUSD с суффиксами; `candles()` читает M5/M15/H1/H4 без текущей открытой свечи; `quote()` возвращает Bid/Ask. После работы вызовите `close()`. Пример:

```python
from gold_ai_trader.mt5_reader import MT5Reader
reader = MT5Reader()
try:
    reader.connect()
    symbols = reader.symbols()
    print(symbols)  # Выберите нужное имя из списка вручную.
    # df = reader.candles(symbols[0], 'M15', 1000)
    # df.to_parquet('gold_m15.parquet', index=False)
finally:
    reader.close()
```

Чтение истории GOLD на демосчёте XM проверено пользователем; чтение спецификации ниже пока не проверено на его терминале. Функция не отключает уже запущенные в терминале советники; используйте отдельный исследовательский терминал без торговых советников. Автоматическое переподключение и удобная команда сохранения истории ещё не реализованы. Пароли в коде не нужны: вход выполняется в самом терминале.

## Первый исследовательский прогноз

После установки зависимостей запустите на сохранённых закрытых свечах M15:

```bat
.venv-gold\Scripts\python.exe -m gold_ai_trader.forecast gold.csv --cost 0.30
```

Модель XGBoost оценивает изменение цены закрытия через четыре свечи; значения SELL/HOLD/BUY — категории движения цены относительно заданного порога в долларах за единицу золота. Значение `0.30` — пример, пользователь должен оценить порог и издержки. Это не доходность сделки и не прогноз с известной достоверностью. Отдельные блоки по времени используются для обучения, калибровки и теста; цели на разрывах времени исключены. Выводятся log loss, многоклассовый Brier, F1 и матрица ошибок. Окончательный статус всегда HOLD: фактическая пригодность, качество калибровки, торговые расходы, walk-forward и свежесть данных ещё не подтверждены. Модель не сохраняется и заново обучается при каждом запуске. Исторический CSV должен содержать только закрытые M15 свечи.

Проверка на нескольких последовательных периодах с фиксированными параметрами и сравнением с простым прогнозом и логистической регрессией:

```bat
.venv-gold\Scripts\python.exe -m gold_ai_trader.research gold.csv --cost 0.30
```

Для каждого периода печатаются log loss и Brier (меньше — лучше), для моделей также F1. Недостаточные периоды выводятся как невыполненные. Итоговый период не используется при обучении моделей данного запуска, но не является независимым финальным тестом, если его уже просматривали в прежних экспериментах. Это проверка классификации движения цены, не торговый backtest и не гарантия качества будущих прогнозов.

## Спецификация и новая учебная разметка

Техническое задание и этапы: [SPECIFICATION_RU.md](docs/SPECIFICATION_RU.md). Чтобы прочитать спецификацию инструмента из открытого демотерминала MT5 (без номера счёта и пароля):

```bat
.venv-gold\Scripts\python.exe -m gold_ai_trader.instrument --symbol GOLD
```

Запишите фактический `point` из результата; не подставляйте предположения. Например, с этим значением можно запустить разметку `gold-more.csv`:

```bat
.venv-gold\Scripts\python.exe -m gold_ai_trader.labeling gold-more.csv --point ФАКТИЧЕСКИЙ_POINT
```

Замените `ФАКТИЧЕСКИЙ_POINT` на число из терминала. Здесь исторический спред каждой свечи используется как приближение спреда на открытии; ATR-коэффициент по умолчанию 0,1 — пример, а нулевые комиссия и проскальзывание — оптимистические допущения. Комиссия задаётся в цене за единицу за полный цикл через `--commission-per-unit`, проскальзывание на одну сторону — через `--slippage`. Без подтверждённых комиссий/проскальзывания результаты нельзя считать реалистичными. Модуль только подсчитывает учебные метки; он не обучает новую модель и не является прогнозом.
